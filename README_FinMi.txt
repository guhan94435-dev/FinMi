=================================================================
          FinMi: AI-POWERED FINANCIAL INTELLIGENCE
=================================================================

FinMi is a strategic financial framework that uses Machine Learning 
and Macro-Economic indicators to provide real-time forecasting.

QUICK START INSTRUCTIONS:
-------------------------
1. Install Python (v3.9 or higher) from python.org.
2. Ensure you have an internet connection for the first run.
3. Double-click "Launch_Financial_App.bat" to start the software.
4. The dashboard will automatically open in your web browser.

HOW TO USE:
-----------
- Use the sidebar to upload your "financial_data.xlsx" file.
- Adjust macro-economic sliders (Inflation, Monsoon, etc.) to 
  see real-time AI-adjusted forecasts.
- Explore the Altman Z-Score risk map and the AI Goal Seek 
  assistant for strategic planning.

FILES IN THIS PACKAGE:
----------------------
- finance_app.py: The core AI engine.
- financial_data.xlsx: The data template.
- Launch_Financial_App.bat: The desktop launcher.
- requirements.txt: List of necessary AI libraries.

Developed as part of an MBA Finance Strategic Project.
